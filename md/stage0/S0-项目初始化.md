# S0-项目初始化

## 一、项目概述

RuoYi 是一个基于 Spring Boot 3 的权限管理系统，采用 RBAC（基于角色的访问控制）模型。本项目经过重构，使用现代化的技术栈和最佳实践。

## 二、技术栈

| 分类 | 技术 | 版本 |
|------|------|------|
| 框架 | Spring Boot | 3.2.5 |
| 语言 | Java | 17+ |
| 持久层 | MyBatis-Plus | 3.5.5 |
| 数据库 | MySQL | 8.0+ |
| 缓存 | Redis | 5.0+ |
| 认证 | JWT | 0.12.5 |
| API文档 | Knife4j | 4.5.0 |
| 对象映射 | MapStruct | 1.5.5 |

## 三、项目结构

```
RuoYi
├── ruoyi-admin          # 启动模块（API 入口）
├── ruoyi-common         # 公共模块（工具类、配置、安全等）
│   ├── core             # 核心常量、异常、统一响应
│   ├── datascope        # 数据权限
│   ├── mybatis          # MyBatis-Plus 配置
│   ├── redis            # Redis 配置
│   └── security         # 安全认证
├── ruoyi-system         # 系统模块（业务逻辑）
│   ├── domain           # 实体、DTO、VO
│   ├── mapper           # 数据访问层
│   └── service          # 业务服务层
└── sql                  # 数据库脚本
```

## 四、数据库表结构

| 表名 | 说明 |
|------|------|
| sys_user | 用户信息表 |
| sys_role | 角色信息表 |
| sys_menu | 菜单权限表 |
| sys_dept | 部门表 |
| sys_user_role | 用户角色关联表 |
| sys_role_menu | 角色菜单关联表 |
| sys_role_dept | 角色部门关联表 |

## 五、环境要求

- JDK 17+
- Maven 3.6+
- MySQL 8.0+
- Redis 5.0+

## 六、启动步骤

1. 执行数据库脚本
   ```bash
   mysql -u root -p < sql/schema.sql
   mysql -u root -p < sql/data.sql
   ```

2. 修改配置文件 `ruoyi-admin/src/main/resources/application-dev.yml`

3. 启动项目
   ```bash
   mvn clean install
   cd ruoyi-admin
   mvn spring-boot:run
   ```

## 七、访问地址

- 项目地址: http://localhost:8080
- API 文档: http://localhost:8080/doc.html
