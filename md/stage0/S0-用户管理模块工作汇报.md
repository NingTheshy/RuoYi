# S0-用户管理模块工作汇报

> 生成日期：2026-07-17
> 状态：✅ 已完成

---

## 一、概述

用户管理模块提供系统用户的增删改查、状态管理、密码重置和角色分配功能。

---

## 二、接口清单

| 接口 | 方法 | 权限标识 | 说明 |
|------|------|---------|------|
| `/system/user/list` | GET | system:user:list | 用户列表（分页） |
| `/system/user/{userId}` | GET | system:user:query | 用户详情 |
| `/system/user` | POST | system:user:add | 新增用户 |
| `/system/user` | PUT | system:user:edit | 修改用户 |
| `/system/user/{userIds}` | DELETE | system:user:remove | 删除用户 |
| `/system/user/resetPwd` | PUT | system:user:resetPwd | 重置密码 |
| `/system/user/changeStatus` | PUT | system:user:edit | 修改用户状态 |
| `/system/user/roles/{userId}` | GET | system:user:query | 获取用户角色ID列表 |
| `/system/user/roles` | PUT | system:user:edit | 分配用户角色 |

## 三、数据链路

### 3.1 用户列表查询

```
GET /system/user/list?pageNum=1&pageSize=10
        │
        ▼
SysUserController.list()
        │
        ▼
SysUserServiceImpl.selectUserList(SysUserQueryReq)
        │
        ├─► MyBatis-Plus 分页查询
        │       └─► sys_user 表
        │
        └─► MapStruct 转换为 SysUserResp
```

### 3.2 新增用户

```
POST /system/user (SysUserCreateReq)
        │
        ▼
SysUserController.create()
        │
        ▼
SysUserServiceImpl.createUser(SysUserCreateReq)
        │
        ├─► 校验用户名唯一性
        │       └─► SysUserMapper.selectUserByUserName()
        │
        ├─► MapStruct 转换为 SysUser
        │
        ├─► BCrypt 加密密码
        │
        ├─► 填充创建人信息
        │
        └─► SysUserMapper.insert()
```

### 3.3 删除用户

```
DELETE /system/user/2,3,4
        │
        ▼
SysUserController.delete()
        │
        ├─► 校验是否包含 admin (userId=1)
        │       └─► 包含则抛出 BusinessException
        │
        └─► SysUserServiceImpl.deleteUserByIds()
                └─► MyBatis-Plus 逻辑删除
```

## 四、关键实现

### 4.1 参数校验

使用 `@Valid` + `jakarta.validation` 注解进行参数校验：

- `@NotBlank` - 必填字段
- `@Size` - 长度限制
- `@Email` - 邮箱格式校验
- `@Pattern` - 正则校验

### 4.2 密码加密

使用 Spring Security 的 `BCryptPasswordEncoder` 进行密码加密存储。

### 4.3 逻辑删除

通过 MyBatis-Plus 的 `@TableLogic` 注解实现逻辑删除，`del_flag` 字段：
- `0` - 存在
- `2` - 删除

### 4.4 数据权限

通过 `@DataScope` 注解实现行级数据权限控制，根据角色的 `dataScope` 字段过滤数据。

## 六、遇到的问题

### 6.1 问题：用户列表查询时部门名称未关联

**解决方法**：在 `SysUserMapper.xml` 中添加部门表关联查询，通过 `dept_id` 关联 `sys_dept` 表获取部门名称。

### 6.2 问题：密码明文存储

**解决方法**：在 Service 层创建用户时使用 `BCryptPasswordEncoder.encode()` 加密密码。
