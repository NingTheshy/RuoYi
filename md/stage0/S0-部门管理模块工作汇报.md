# S0-部门管理模块工作汇报

> 生成日期：2026-07-17
> 状态：✅ 已完成

---

## 一、概述

部门管理模块提供部门的增删改查和树形结构管理功能，支持数据权限控制。

---

## 二、接口清单

| 接口 | 方法 | 权限标识 | 说明 |
|------|------|---------|------|
| `/system/dept/list` | GET | system:dept:list | 部门列表 |
| `/system/dept/{deptId}` | GET | system:dept:query | 部门详情 |
| `/system/dept` | POST | system:dept:add | 新增部门 |
| `/system/dept` | PUT | system:dept:edit | 修改部门 |
| `/system/dept/{deptId}` | DELETE | system:dept:remove | 删除部门 |

---

## 三、数据链路

### 3.1 新增部门

```
POST /system/dept (SysDeptCreateReq)
        │
        ▼
SysDeptController.create()
        │
        ▼
SysDeptServiceImpl.createDept(SysDeptCreateReq)
        │
        ├─► MapStruct 转换为 SysDept
        │
        ├─► 校验部门名称唯一性
        │
        ├─► 计算祖级列表 ancestors
        │       └─► 查询父部门的 ancestors + 父部门ID
        │
        └─► SysDeptMapper.insert()
```

### 3.2 删除部门

```
DELETE /system/dept/103
        │
        ▼
SysDeptController.delete()
        │
        ├─► 查询是否有子部门
        │       └─► SysDeptMapper.selectCountByParentId()
        │       └─► 有子部门则抛出异常
        │
        ├─► 查询是否有用户
        │       └─► SysUserMapper.selectCountByDeptId()
        │       └─► 有用户则抛出异常
        │
        └─► 删除部门
                └─► SysDeptMapper.deleteById()
```

---

## 四、关键实现

### 4.1 祖级列表

`ancestors` 字段存储部门的祖级路径，格式为 `0,100,101`，便于查询子部门数据。

### 4.2 数据权限关联

部门管理与角色的数据权限紧密关联，角色的 `dataScope` 字段决定了用户能看到哪些部门的数据。
