# S0-菜单管理模块工作汇报

> 生成日期：2026-07-17
> 状态：✅ 已完成

---

## 一、概述

菜单管理模块提供系统菜单的增删改查、树形结构管理和权限标识配置功能。支持目录(M)、菜单(C)、按钮(F)三种类型。

---

## 二、接口清单

| 接口 | 方法 | 权限标识 | 说明 |
|------|------|---------|------|
| `/system/menu/list` | GET | system:menu:list | 菜单列表 |
| `/system/menu/{menuId}` | GET | system:menu:query | 菜单详情 |
| `/system/menu` | POST | system:menu:add | 新增菜单 |
| `/system/menu` | PUT | system:menu:edit | 修改菜单 |
| `/system/menu/{menuId}` | DELETE | system:menu:remove | 删除菜单 |
| `/system/menu/treeselect` | GET | system:menu:list | 获取菜单树（角色授权用） |
| `/system/menu/role-menu-tree-select/{roleId}` | GET | system:role:query | 获取角色已授权菜单ID |

---

## 三、数据链路

### 3.1 新增菜单

```
POST /system/menu (SysMenuCreateReq)
        │
        ▼
SysMenuController.create()
        │
        ▼
SysMenuServiceImpl.createMenu(SysMenuCreateReq)
        │
        ├─► MapStruct 转换为 SysMenu
        │
        ├─► 校验菜单名称唯一性
        │
        └─► SysMenuMapper.insert()
```

### 3.2 删除菜单

```
DELETE /system/menu/100
        │
        ▼
SysMenuController.delete()
        │
        ├─► 查询是否有子菜单
        │       └─► SysMenuMapper.selectCountByParentId()
        │       └─► 有子菜单则抛出异常
        │
        ├─► 删除角色菜单关联
        │       └─► SysRoleMenuMapper.deleteByMenuId()
        │
        └─► 删除菜单
                └─► SysMenuMapper.deleteById()
```

## 四、关键实现

### 4.1 菜单类型

| 值 | 说明 | 特点 |
|----|------|------|
| M | 目录 | 无路由地址，无组件路径 |
| C | 菜单 | 有路由地址和组件路径 |
| F | 按钮 | 无路由地址，有权限标识 |

### 4.2 菜单树构建

通过 `parentId` 字段构建树形结构，前端或后端均可组装。

### 4.3 权限标识

`perms` 字段存储权限标识，如 `system:user:list`，用于 Spring Security 的 `@PreAuthorize` 注解校验。
