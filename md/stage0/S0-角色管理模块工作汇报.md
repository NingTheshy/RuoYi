# S0-角色管理模块工作汇报

> 生成日期：2026-07-17
> 状态：✅ 已完成

---

## 一、概述

角色管理模块提供角色的增删改查、菜单授权和数据范围配置功能。

---

## 二、接口清单

| 接口 | 方法 | 权限标识 | 说明 |
|------|------|---------|------|
| `/system/role/list` | GET | system:role:list | 角色列表（分页） |
| `/system/role/{roleId}` | GET | system:role:query | 角色详情 |
| `/system/role` | POST | system:role:add | 新增角色 |
| `/system/role` | PUT | system:role:edit | 修改角色 |
| `/system/role/{roleIds}` | DELETE | system:role:remove | 删除角色 |

---

## 三、数据链路

### 3.1 新增角色

```
POST /system/role (SysRoleCreateReq)
        │
        ▼
SysRoleController.create()
        │
        ▼
SysRoleServiceImpl.createRole(SysRoleCreateReq)
        │
        ├─► 校验角色标识唯一性
        │       └─► SysRoleMapper.selectRoleByRoleKey()
        │
        ├─► MapStruct 转换为 SysRole
        │
        ├─► SysRoleMapper.insert()
        │
        └─► 批量插入角色菜单关联
                └─► SysRoleMenuMapper.batchInsert()
```

### 3.2 删除角色

```
DELETE /system/role/2,3
        │
        ▼
SysRoleController.delete()
        │
        ├─► 校验是否包含 admin 角色 (roleId=1)
        │
        ├─► 删除角色菜单关联
        │       └─► SysRoleMenuMapper.deleteByRoleIds()
        │
        ├─► 删除角色部门关联
        │       └─► SysRoleDeptMapper.deleteByRoleIds()
        │
        ├─► 删除用户角色关联
        │       └─► SysUserRoleMapper.deleteByRoleIds()
        │
        └─► 删除角色
                └─► SysRoleMapper.deleteByIds()
```

## 四、关键实现

### 4.1 数据范围配置

角色的 `dataScope` 字段控制行级数据权限：

| 值 | 说明 |
|----|------|
| 1 | 全部数据权限 |
| 2 | 自定义数据权限（需关联 sys_role_dept） |
| 3 | 本部门数据权限 |
| 4 | 本部门及以下数据权限 |
| 5 | 仅本人数据权限 |

### 4.2 菜单树关联

通过 `menuCheckStrictly` 和 `deptCheckStrictly` 字段控制树选择时是否关联父节点。
