## 一、需求分析

### 1.1 业务背景

在线用户管理用于监控当前系统中活跃用户的状态，管理员可以查看在线用户列表，并强制下线指定用户。

### 1.2 功能需求

| 需求点 | 描述 | 优先级 |
|--------|------|--------|
| 在线用户列表 | 查询当前在线用户列表 | P0 |
| 强制下线 | 强制指定用户下线 | P0 |

### 1.3 非功能需求

- 基于 Redis 存储在线用户信息
- 用户登出/Token过期时自动移除在线状态

---

## 二、技术方案

### 2.1 Redis Key 设计

| Key | 说明 | 过期时间 |
|-----|------|---------|
| login_tokens:{userId} | 存储用户的有效 Token | 24小时 |
| login_user:{userId} | 存储在线用户信息 | 24小时 |

### 2.2 在线用户信息结构

```json
{
  "token": "eyJhbGciOiJIUzI1NiJ9...",
  "userId": 1,
  "userName": "admin",
  "nickName": "若依管理员",
  "deptName": "研发部门",
  "loginTime": "2026-07-17 10:00:00",
  "loginIp": "127.0.0.1"
}
```

### 2.3 接口设计

#### 2.3.1 在线用户列表

```
GET /monitor/online/list
```

**成功响应**：

```json
{
  "code": 200,
  "data": [
    {
      "tokenId": "login_user:1",
      "userId": 1,
      "userName": "admin",
      "nickName": "若依管理员",
      "deptName": "研发部门",
      "loginTime": "2026-07-17 10:00:00",
      "loginIp": "127.0.0.1",
      "expireTime": "2026-07-18 10:00:00"
    }
  ]
}
```

#### 2.3.2 强制下线

```
DELETE /monitor/online/{tokenId}
```

**路径参数**：

| 参数 | 类型 | 说明 |
|------|------|------|
| tokenId | String | Redis Key，如 `login_user:1` |

**成功响应**：

```json
{
  "code": 200,
  "msg": "操作成功",
  "data": null
}
```

### 2.4 权限标识

| 权限标识 | 说明 |
|---------|------|
| monitor:online:list | 查询在线用户列表 |
| monitor:online:remove | 强制下线用户 |

## 四、在线用户维护流程

### 4.1 用户登录时

```
用户登录成功
    │
    ├─► Redis 设置 login_tokens:{userId} = token
    │
    └─► Redis 设置 login_user:{userId} = 用户信息
```

### 4.2 用户登出时

```
用户登出
    │
    ├─► Redis 删除 login_tokens:{userId}
    │
    └─► Redis 删除 login_user:{userId}
```

### 4.3 Token过期时

```
Token过期
    │
    └─► Redis 自动过期，在线用户信息失效
```

## 六、测试用例

| 测试场景 | 请求 | 预期结果 |
|---------|------|---------|
| 查询在线用户列表 | `GET /monitor/online/list` | 返回在线用户列表 |
| 用户登录后出现在线列表 | 调用登录接口成功 | 在线列表包含该用户 |
| 用户登出后从在线列表消失 | 调用登出接口 | 在线列表不再包含该用户 |
| 强制下线用户 | `DELETE /monitor/online/login_user:1` | 用户被强制下线 |
| 权限不足访问 | 无权限用户访问 | 返回 403 |
