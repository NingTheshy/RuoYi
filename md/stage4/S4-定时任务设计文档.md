## 一、需求分析

### 1.1 业务背景

定时任务用于在线配置和管理定时调度任务，支持 Cron 表达式，方便执行批量处理、数据同步等操作。

### 1.2 功能需求

| 需求点 | 描述 | 优先级 |
|--------|------|--------|
| 任务列表 | 查询定时任务列表，支持分页和筛选 | P0 |
| 任务详情 | 根据任务ID查询任务详情 | P0 |
| 新增任务 | 创建新的定时任务 | P0 |
| 修改任务 | 更新已有的定时任务 | P0 |
| 删除任务 | 删除指定的定时任务 | P0 |
| 改变状态 | 启用/停用定时任务 | P0 |
| 立即执行 | 立即执行一次定时任务 | P0 |
| 任务日志 | 查询任务执行日志 | P0 |

### 1.3 非功能需求

- 支持 Cron 表达式验证
- 任务执行失败时记录日志
- 支持并发执行控制

## 二、技术方案

### 2.1 数据库设计

#### sys_job 表（定时任务表）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| job_id | BIGINT | PRIMARY KEY, AUTO_INCREMENT | 任务ID |
| job_name | VARCHAR(64) | NOT NULL | 任务名称 |
| job_group | VARCHAR(64) | DEFAULT 'DEFAULT' | 任务分组 |
| job_class_name | VARCHAR(255) | NOT NULL | 任务执行类全限定名 |
| cron_expression | VARCHAR(128) | NOT NULL | Cron表达式 |
| misfire_policy | VARCHAR(20) | DEFAULT '3' | 错过策略（1立即执行 2执行一次 3放弃执行） |
| concurrent | CHAR(1) | DEFAULT '1' | 是否并发（0禁止 1允许） |
| status | CHAR(1) | DEFAULT '0' | 状态（0正常 1停用） |
| create_by | VARCHAR(64) | DEFAULT '' | 创建者 |
| create_time | DATETIME | DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| update_by | VARCHAR(64) | DEFAULT '' | 更新者 |
| update_time | DATETIME | NULL ON UPDATE CURRENT_TIMESTAMP | 更新时间 |
| remark | VARCHAR(500) | NULL | 备注 |

#### sys_job_log 表（任务日志表）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| job_log_id | BIGINT | PRIMARY KEY, AUTO_INCREMENT | 日志ID |
| job_name | VARCHAR(64) | NOT NULL | 任务名称 |
| job_group | VARCHAR(64) | DEFAULT 'DEFAULT' | 任务分组 |
| job_class_name | VARCHAR(255) | NOT NULL | 任务执行类全限定名 |
| cron_expression | VARCHAR(128) | NOT NULL | Cron表达式 |
| status | CHAR(1) | DEFAULT '0' | 状态（0成功 1失败） |
| error_msg | VARCHAR(2000) | DEFAULT '' | 错误信息 |
| job_time | DATETIME | DEFAULT CURRENT_TIMESTAMP | 执行时间 |
| create_time | DATETIME | DEFAULT CURRENT_TIMESTAMP | 创建时间 |

### 2.2 接口设计

#### 2.2.1 任务列表

```
GET /monitor/job/list
```

**请求参数**：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| pageNum | Integer | ❌ | 页码，默认 1 |
| pageSize | Integer | ❌ | 每页条数，默认 10 |
| jobName | String | ❌ | 任务名称，模糊匹配 |
| jobGroup | String | ❌ | 任务分组，模糊匹配 |
| status | String | ❌ | 状态（0正常 1停用） |

**成功响应**：

```json
{
  "code": 200,
  "data": {
    "total": 5,
    "rows": [
      {
        "jobId": 1,
        "jobName": "数据同步任务",
        "jobGroup": "DEFAULT",
        "jobClassName": "com.ruoyi.system.job.DataSyncJob",
        "cronExpression": "0 0 2 * * ?",
        "misfirePolicy": "3",
        "concurrent": "1",
        "status": "0",
        "remark": "每天凌晨2点执行",
        "createTime": "2026-07-17 10:00:00"
      }
    ]
  }
}
```

## 四、Quartz 集成

### 4.1 依赖添加

```xml
<dependency>
    <groupId>org.quartz-scheduler</groupId>
    <artifactId>quartz</artifactId>
    <version>2.3.2</version>
</dependency>
```

### 4.2 任务存储

使用数据库存储 Quartz 调度信息，需要添加 Quartz 相关表（QRTZ_*）。

### 4.3 任务执行流程

```
定时触发
    │
    ▼
Quartz Scheduler
    │
    ├─► 获取任务信息
    │
    ├─► JobInvokeUtil.invokeMethod(job)
    │     └─► 反射调用 jobClassName 的 execute 方法
    │
    ├─► 记录执行日志
    │
    └─► 处理异常
          └─► 更新日志状态为失败
```

## 六、数据库脚本

```sql
-- 定时任务表
DROP TABLE IF EXISTS sys_job;
CREATE TABLE sys_job (
    job_id          BIGINT NOT NULL AUTO_INCREMENT COMMENT '任务ID',
    job_name        VARCHAR(64) NOT NULL COMMENT '任务名称',
    job_group       VARCHAR(64) DEFAULT 'DEFAULT' COMMENT '任务分组',
    job_class_name  VARCHAR(255) NOT NULL COMMENT '任务执行类全限定名',
    cron_expression VARCHAR(128) NOT NULL COMMENT 'Cron表达式',
    misfire_policy  VARCHAR(20) DEFAULT '3' COMMENT '错过策略（1立即执行 2执行一次 3放弃执行）',
    concurrent      CHAR(1) DEFAULT '1' COMMENT '是否并发（0禁止 1允许）',
    status          CHAR(1) DEFAULT '0' COMMENT '状态（0正常 1停用）',
    create_by       VARCHAR(64) DEFAULT '' COMMENT '创建者',
    create_time     DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    update_by       VARCHAR(64) DEFAULT '' COMMENT '更新者',
    update_time     DATETIME DEFAULT NULL ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    remark          VARCHAR(500) DEFAULT NULL COMMENT '备注',
    PRIMARY KEY (job_id)
) ENGINE=InnoDB AUTO_INCREMENT=100 COMMENT='定时任务表';

-- 任务日志表
DROP TABLE IF EXISTS sys_job_log;
CREATE TABLE sys_job_log (
    job_log_id      BIGINT NOT NULL AUTO_INCREMENT COMMENT '日志ID',
    job_name        VARCHAR(64) NOT NULL COMMENT '任务名称',
    job_group       VARCHAR(64) DEFAULT 'DEFAULT' COMMENT '任务分组',
    job_class_name  VARCHAR(255) NOT NULL COMMENT '任务执行类全限定名',
    cron_expression VARCHAR(128) NOT NULL COMMENT 'Cron表达式',
    status          CHAR(1) DEFAULT '0' COMMENT '状态（0成功 1失败）',
    error_msg       VARCHAR(2000) DEFAULT '' COMMENT '错误信息',
    job_time        DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '执行时间',
    create_time     DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    PRIMARY KEY (job_log_id)
) ENGINE=InnoDB AUTO_INCREMENT=100000 COMMENT='任务日志表';
```
