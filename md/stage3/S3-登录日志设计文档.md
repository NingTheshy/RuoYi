## 一、需求分析

### 1.1 业务背景

登录日志用于记录用户的登录行为，包括登录成功、登录失败等情况，便于安全审计和问题排查。

### 1.2 功能需求

| 需求点 | 描述 | 优先级 |
|--------|------|--------|
| 日志列表 | 查询登录日志列表，支持分页和筛选 | P0 |
| 删除日志 | 删除指定的登录日志 | P0 |
| 清空日志 | 清空所有登录日志 | P0 |

### 1.3 非功能需求

- 在登录成功/失败时自动记录日志
- 支持记录登录IP、登录地点、浏览器信息等

## 二、技术方案

### 2.1 数据库设计

#### sys_login_log 表

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| info_id | BIGINT | PRIMARY KEY, AUTO_INCREMENT | 日志ID |
| user_name | VARCHAR(50) | DEFAULT '' | 用户名称 |
| ip_addr | VARCHAR(128) | DEFAULT '' | IP地址 |
| login_location | VARCHAR(255) | DEFAULT '' | 登录地点 |
| browser | VARCHAR(50) | DEFAULT '' | 浏览器类型 |
| os | VARCHAR(50) | DEFAULT '' | 操作系统 |
| status | CHAR(1) | DEFAULT '0' | 登录状态（0成功 1失败） |
| msg | VARCHAR(255) | DEFAULT '' | 提示信息 |
| login_time | DATETIME | DEFAULT CURRENT_TIMESTAMP | 登录时间 |

### 2.2 接口设计

#### 2.2.1 登录日志列表

```
GET /monitor/logininfor/list
```

**请求参数**：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| pageNum | Integer | ❌ | 页码，默认 1 |
| pageSize | Integer | ❌ | 每页条数，默认 10 |
| userName | String | ❌ | 用户名称，模糊匹配 |
| ipAddr | String | ❌ | IP地址，模糊匹配 |
| status | String | ❌ | 登录状态（0成功 1失败） |
| beginTime | String | ❌ | 开始时间 |
| endTime | String | ❌ | 结束时间 |

**成功响应**：

```json
{
  "code": 200,
  "data": {
    "total": 50,
    "rows": [
      {
        "infoId": 1,
        "userName": "admin",
        "ipAddr": "127.0.0.1",
        "loginLocation": "本地",
        "browser": "Chrome",
        "os": "Windows",
        "status": "0",
        "msg": "登录成功",
        "loginTime": "2026-07-17 10:00:00"
      }
    ]
  }
}
```

#### 2.2.2 删除登录日志

```
DELETE /monitor/logininfor/{infoIds}
```

**成功响应**：

```json
{
  "code": 200,
  "msg": "操作成功",
  "data": null
}
```

#### 2.2.3 清空登录日志

```
DELETE /monitor/logininfor/clean
```

**成功响应**：同上

### 2.3 权限标识

| 权限标识 | 说明 |
|---------|------|

| monitor:logininfor:remove | 删除登录日志 |

## 四、登录日志记录时机

在 `LoginService.login()` 方法中，登录成功和失败时都需要记录日志：

```
登录请求
    │
    ├─► 登录成功
    │     └─► 记录日志：status=0, msg="登录成功"
    │
    └─► 登录失败
          └─► 记录日志：status=1, msg="密码错误"/"用户不存在"/"用户已停用"
```

## 六、数据库脚本

```sql
-- 登录日志表
DROP TABLE IF EXISTS sys_login_log;
CREATE TABLE sys_login_log (
    info_id         BIGINT NOT NULL AUTO_INCREMENT COMMENT '日志ID',
    user_name       VARCHAR(50) DEFAULT '' COMMENT '用户名称',
    ip_addr         VARCHAR(128) DEFAULT '' COMMENT 'IP地址',
    login_location  VARCHAR(255) DEFAULT '' COMMENT '登录地点',
    browser         VARCHAR(50) DEFAULT '' COMMENT '浏览器类型',
    os              VARCHAR(50) DEFAULT '' COMMENT '操作系统',
    status          CHAR(1) DEFAULT '0' COMMENT '登录状态（0成功 1失败）',
    msg             VARCHAR(255) DEFAULT '' COMMENT '提示信息',
    login_time      DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '登录时间',
    PRIMARY KEY (info_id)
) ENGINE=InnoDB AUTO_INCREMENT=100000 COMMENT='登录日志表';
```
