## 一、需求分析

### 1.1 业务背景

服务监控用于查看系统运行状态，包括服务器信息、内存使用、CPU使用、磁盘使用等，便于运维人员了解系统健康状况。

### 1.2 功能需求

| 需求点 | 描述 | 优先级 |
|--------|------|--------|
| 服务器信息 | 获取服务器基本信息 | P0 |
| JVM信息 | 获取JVM运行信息 | P0 |
| 磁盘信息 | 获取磁盘使用信息 | P0 |

### 1.3 非功能需求

- 实时获取系统状态
- 不影响系统性能

## 二、技术方案

### 2.1 接口设计

#### 2.1.1 服务器信息

```
GET /monitor/server
```

**成功响应**：

```json

  "data": {

      "runTime": "2小时30分钟"
    },
    "cpuInfo": {
      "cpuCores": 8,
      "cpuUsage": 25.5
    },
    "memoryInfo": {
      "totalMemory": "8.0 GB",
      "usedMemory": "2.5 GB",

    "diskInfo": {
```

#### 2.1.2 数据源信息（可选）

```
GET /monitor/datasource
```

**成功响应**：

```json
{
  "code": 200,
  "data": {
    "datasourceName": "master",
    "url": "jdbc:mysql://localhost:3306/ry",
    "username": "root",
    "connectionCount": 10,
    "activeCount": 2,
    "maxActive": 20
  }
}
```

### 2.2 权限标识

| 权限标识 | 说明 |
|---------|------|
| monitor:server | 查看服务器信息 |
| monitor:datasource | 查看数据源信息 |

## 三、代码结构

```
ruoyi-system/
├── domain/
│   └── dto/
│       └── monitor/
│           ├── ServerInfoResp.java    # 服务器信息响应DTO
│           ├── CpuInfo.java           # CPU信息
│           ├── MemoryInfo.java        # 内存信息
│           ├── DiskInfo.java          # 磁盘信息

├── service/
│   ├── ServerMonitorService.java     # Service接口
│   └── impl/
│       └── ServerMonitorServiceImpl.java # Service实现

ruoyi-admin/
└── web/
    └── monitor/
        └── SysMonitorController.java  # Controller
```

## 五、测试用例

| 测试场景 | 请求 | 预期结果 |
