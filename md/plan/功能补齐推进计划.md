# RuoYi 功能补齐推进计划

## 文档说明

本文档为 RuoYi 权限管理系统功能补齐的详细推进计划，按照"一个功能一个功能堆上去"的形式，分阶段、分任务逐步完善系统功能。

---

## 总体路线图

```
阶段1 (核心基础)  →  阶段2 (常用功能)  →  阶段3 (重要功能)  →  阶段4 (增强功能)  →  阶段5 (高级功能)
岗位管理          →  参数配置          →  操作日志          →  定时任务          →  代码生成
字典管理          →  通知公告          →  登录日志          →  在线用户          →  服务监控
```

---

## 标准开发流程

每个任务遵循以下标准流程：

| 序号 | 步骤 | 说明 |
|------|------|------|
| 1 | 确认设计文档 | 检查 `stageX/SX-xxx设计文档.md` |
| 2 | 创建数据库表 | 添加表结构和索引到 `sql/schema.sql` |
| 3 | 创建实体类 | 在 `ruoyi-system/src/main/java/com/ruoyi/system/domain/entity/` |
| 4 | 创建DTO | 在 `ruoyi-system/src/main/java/com/ruoyi/system/domain/dto/` |
| 5 | 创建Mapper | 在 `ruoyi-system/src/main/java/com/ruoyi/system/mapper/` |
| 6 | 创建Mapper XML | 在 `ruoyi-system/src/main/resources/mapper/` |
| 7 | 创建Service接口 | 在 `ruoyi-system/src/main/java/com/ruoyi/system/service/` |
| 8 | 创建Service实现 | 在 `ruoyi-system/src/main/java/com/ruoyi/system/service/impl/` |
| 9 | 创建Convert | 在 `ruoyi-system/src/main/java/com/ruoyi/system/convert/` |
| 10 | 创建Controller | 在 `ruoyi-admin/src/main/java/com/ruoyi/admin/web/system/` |
| 11 | 添加菜单和权限 | 在 `sql/data.sql` 中配置菜单和按钮权限 |
| 12 | 接口测试验证 | 使用 Knife4j 测试接口功能 |
| 13 | 编写工作汇报 | 在 `stageX/SX-xxx工作汇报.md` 记录实现总结 |
| 14 | 更新计划状态 | 修改本文档状态标记 |

**数据库表结构**：

```sql
-- 岗位表
DROP TABLE IF EXISTS sys_post;
CREATE TABLE sys_post (
    post_id      BIGINT NOT NULL AUTO_INCREMENT COMMENT '岗位ID',
    post_code    VARCHAR(64) NOT NULL UNIQUE COMMENT '岗位编码',
    post_name    VARCHAR(50) NOT NULL COMMENT '岗位名称',
    post_sort    INT DEFAULT 0 COMMENT '显示顺序',
    status       CHAR(1) DEFAULT '0' COMMENT '状态（0正常 1停用）',
    create_by    VARCHAR(64) DEFAULT '' COMMENT '创建者',
    create_time  DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    update_by    VARCHAR(64) DEFAULT '' COMMENT '更新者',
    update_time  DATETIME DEFAULT NULL ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    remark       VARCHAR(500) DEFAULT NULL COMMENT '备注',
    del_flag     CHAR(1) DEFAULT '0' COMMENT '删除标志（0存在 2删除）',
    PRIMARY KEY (post_id),
    INDEX idx_post_code (post_code),
    INDEX idx_post_name (post_name),
    INDEX idx_status (status)
) ENGINE=InnoDB AUTO_INCREMENT=100 COMMENT='岗位信息表';

-- 用户表添加岗位字段
ALTER TABLE sys_user ADD COLUMN post_id BIGINT DEFAULT NULL COMMENT '岗位ID' AFTER dept_id;
ALTER TABLE sys_user ADD INDEX idx_post_id (post_id);
```
