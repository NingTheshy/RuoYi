# S1-岗位管理工作汇报

> 生成日期：2026-07-22
> 状态：✅ 已完成

---

## 一、概述

岗位管理模块提供岗位信息的增删改查功能，用于配置用户所属职务。岗位与用户通过 `sys_user_post` 关联表进行多对多关联。

---

## 二、接口清单

| 接口 | 方法 | 权限标识 | 说明 |
|------|------|---------|------|
| `/system/post/list` | GET | system:post:list | 分页查询岗位列表 |
| `/system/post/{postId}` | GET | system:post:query | 查询岗位详情 |
| `/system/post` | POST | system:post:add | 新增岗位 |
| `/system/post` | PUT | system:post:edit | 修改岗位 |
| `/system/post/{postIds}` | DELETE | system:post:remove | 批量删除岗位 |

---

## 三、接口详细数据链路

### 3.1 分页查询岗位列表 `GET /system/post/list`

**请求参数**：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| pageNum | Integer | ❌ | 页码，默认 1 |
| pageSize | Integer | ❌ | 每页条数，默认 10 |
| postName | String | ❌ | 岗位名称，模糊匹配 |
| postCode | String | ❌ | 岗位编码，模糊匹配 |
| status | String | ❌ | 状态（0正常 1停用） |

**数据链路**：

```
GET /system/post/list?postName=管理员&pageNum=1&pageSize=10
        │
        ▼
SysPostController.list()
        │
        ▼
SysPostServiceImpl.getPostPage()
        │
        ├─ MapStruct (SysPostConvert) 做字段映射
        │   SysPostQueryReq → SysPost
        │
        └─ MyBatis-Plus selectPage():
              SELECT * FROM sys_post 
              WHERE post_name LIKE '%管理员%' AND del_flag = '0'
              ORDER BY post_sort ASC
              LIMIT 0, 10
```

**响应结构**：

```json
{
  "code": 200,
  "data": {
    "total": 1,
    "rows": [
      {
        "postId": 1,
        "postCode": "admin",
        "postName": "管理员",
        "postSort": 1,
        "status": "0",
        "remark": "管理员岗位",
        "createTime": "2026-07-22 10:00:00"
      }
    ]
  }
}
```

### 3.2 新增岗位 `POST /system/post`

**请求体**：

```json
{
  "postCode": "developer",
  "postName": "开发工程师",
  "postSort": 2,
  "status": "0",
  "remark": "开发岗位"
}
```

**数据链路**：

```
POST /system/post (JSON Body)
        │
        ▼
SysPostController.add()
        │
        ▼
SysPostServiceImpl.createPost()
        │
        ├─ MapStruct (SysPostConvert) 做字段映射
        │   SysPostCreateReq → SysPost
        │
        ├─ 校验岗位编码唯一性:
        │   SysPostMapper.selectPostByCode(postCode)
        │   └─ 已存在则抛出 ServiceException(400)
        │
        ├─ 设置默认值:
        │   ├─ status = "0"（正常状态）
        │   └─ postSort = 0（未指定时）
        │
        └─ SysPostMapper.insert() → sys_post 表
```

---

### 3.3 修改岗位 `PUT /system/post`

**请求体**：

```json
{
  "postId": 2,
  "postCode": "developer",
  "postName": "高级开发工程师",
  "postSort": 2,
  "status": "0"
}
```

**数据链路**：

```
PUT /system/post (JSON Body)
        │
        ▼
SysPostController.edit()
        │
        ▼
SysPostServiceImpl.updatePost()
        │
        ├─ SysPostMapper.selectById(postId)
        │   └─ 不存在则抛出 ServiceException(404)
        │
        ├─ MapStruct (SysPostConvert) 做字段映射
        │   SysPostUpdateReq → SysPost
        │
        ├─ 校验岗位编码唯一性（排除自身）:
        │   SysPostMapper.selectPostByCode(postCode)
        │
        └─ SysPostMapper.updateById() → sys_post 表
```

---

### 3.4 删除岗位 `DELETE /system/post/{postIds}`

**数据链路**：

```
DELETE /system/post/2,3
        │
        ▼
SysPostController.remove()
        │
        ▼
SysPostServiceImpl.deletePostByIds()
        │
        ├─ 遍历每个 postId:
        │   └─ SysPostMapper.countUserPost(postId)
        │       └─ 存在关联用户则抛出 ServiceException
        │
        └─ SysPostMapper.deleteBatchIds() → sys_post 表（逻辑删除）
```

## 四、关键实现

### 4.1 数据库表结构

**sys_post 表**：

| 字段 | 类型 | 说明 |
|------|------|------|
| post_id | BIGINT | 岗位ID（主键，自增） |
| post_code | VARCHAR(64) | 岗位编码（唯一） |
| post_name | VARCHAR(50) | 岗位名称 |
| post_sort | INT | 显示顺序 |
| status | CHAR(1) | 状态（0正常 1停用） |
| del_flag | CHAR(1) | 删除标志（0存在 2删除） |

**sys_user_post 表**（用户-岗位关联）：

| 字段 | 类型 | 说明 |
|------|------|------|
| user_id | BIGINT | 用户ID |
| post_id | BIGINT | 岗位ID |

### 4.2 逻辑删除

使用 MyBatis-Plus 的 `@TableLogic` 注解实现逻辑删除：
- 删除时 `del_flag` 从 `0` 更新为 `2`
- 查询时自动过滤 `del_flag = '0'` 的记录

### 4.3 权限校验

每个接口使用 `@PreAuthorize("hasAuthority('system:post:xxx')")` 进行权限校验。
