# S1-字典管理工作汇报

> 生成日期：2026-07-22
> 状态：✅ 已完成

---

## 一、概述

字典管理模块用于维护系统中经常使用的固定数据，分为字典类型管理和字典数据管理两部分。字典数据支持 Redis 缓存，提高查询性能。

---

## 二、接口清单

### 2.1 字典类型接口

| 接口 | 方法 | 权限标识 | 说明 |
|------|------|---------|------|
| `/system/dict/type/list` | GET | system:dict:type:list | 分页查询字典类型列表 |
| `/system/dict/type` | POST | system:dict:type:add | 新增字典类型 |
| `/system/dict/type` | PUT | system:dict:type:edit | 修改字典类型 |
| `/system/dict/type/{dictIds}` | DELETE | system:dict:type:remove | 批量删除字典类型 |

### 2.2 字典数据接口

| 接口 | 方法 | 权限标识 | 说明 |
|------|------|---------|------|
| `/system/dict/data/list` | GET | system:dict:data:list | 分页查询字典数据列表 |
| `/system/dict/data` | POST | system:dict:data:add | 新增字典数据 |
| `/system/dict/data` | PUT | system:dict:data:edit | 修改字典数据 |
| `/system/dict/data/{dictCodes}` | DELETE | system:dict:data:remove | 批量删除字典数据 |
| `/system/dict/data/type/{dictType}` | GET | 无 | 按类型获取字典数据（下拉选项） |

## 三、接口详细数据链路

### 3.1 新增字典类型 `POST /system/dict/type`

**请求体**：

```json
{
  "dictName": "用户状态",
  "dictType": "sys_user_status",
  "status": "0",
  "remark": "用户状态字典"
}
```

**数据链路**：

```
POST /system/dict/type (JSON Body)
        │
        ▼
SysDictTypeController.add()
        │
        ▼
SysDictTypeServiceImpl.createDictType()
        │
        ├─ MapStruct (SysDictTypeConvert) 做字段映射
        │   SysDictTypeCreateReq → SysDictType
        │
        ├─ 校验字典类型唯一性:
        │   SysDictTypeMapper.selectDictTypeByType(dictType)
        │   └─ 已存在则抛出 ServiceException(400)
        │
        ├─ 设置默认值:
        │   └─ status = "0"（正常状态）
        │
        └─ SysDictTypeMapper.insert() → sys_dict_type 表
```

---

### 3.2 新增字典数据 `POST /system/dict/data`

**请求体**：

```json
{
  "dictSort": 1,
  "dictLabel": "正常",
  "dictValue": "0",
  "dictType": "sys_user_status",
  "isDefault": "Y",
  "status": "0"
}
```

**数据链路**：

```
POST /system/dict/data (JSON Body)
        │
        ▼
SysDictDataController.add()
        │
        ▼
SysDictDataServiceImpl.createDictData()
        │
        ├─ MapStruct (SysDictDataConvert) 做字段映射
        │   SysDictDataCreateReq → SysDictData
        │
        ├─ 设置默认值:
        │   ├─ status = "0"（正常状态）
        │   ├─ isDefault = "N"（非默认）
        │   └─ dictSort = 0（未指定时）
        │
        ├─ SysDictDataMapper.insert() → sys_dict_data 表
        │
        └─ Redis 删除缓存:
              Key: dict:type:sys_user_status
```

---

### 3.3 按类型获取字典数据 `GET /system/dict/data/type/{dictType}`

**数据链路**（带缓存）：

```
GET /system/dict/data/type/sys_user_sex
        │
        ▼
SysDictDataController.getDictDataByType()
        │
        ▼
SysDictDataServiceImpl.getDictDataByType()
        │
        ├─ Redis 查询缓存:
        │   Key: dict:type:sys_user_sex
        │   └─ 命中则直接返回缓存数据
        │
        ├─ Redis 未命中，查询数据库:
        │   SysDictDataMapper.selectDictDataByType(dictType)
        │   └─ 只查询 status = '0' 的记录
        │
        ├─ MapStruct 转换为 DictDataOptionResp 列表
        │
        └─ Redis 写入缓存:
              Key: dict:type:sys_user_sex
              Expire: 1小时
```

**响应结构**：

```json
{
  "code": 200,
  "data": [
    { "dictLabel": "男", "dictValue": "0" },
    { "dictLabel": "女", "dictValue": "1" },
    { "dictLabel": "未知", "dictValue": "2" }
  ]
}
```

---

### 3.4 删除字典类型 `DELETE /system/dict/type/{dictIds}`

**数据链路**：

```
DELETE /system/dict/type/3
        │
        ▼
SysDictTypeController.remove()
        │
        ▼
SysDictTypeServiceImpl.deleteDictTypeByIds()
        │
        ├─ 遍历每个 dictId:
        │   ├─ SysDictDataMapper.countDictDataByType(dictType)
        │   │   └─ 存在关联数据则抛出 ServiceException
        │   │
        │   └─ Redis 删除缓存:
        │         Key: dict:type:{dictType}
        │
        └─ SysDictTypeMapper.deleteBatchIds() → sys_dict_type 表
```

## 四、关键实现

### 4.1 数据库表结构

**sys_dict_type 表**（字典类型）：

| 字段 | 类型 | 说明 |
|------|------|------|
| dict_id | BIGINT | 字典类型ID（主键，自增） |
| dict_name | VARCHAR(100) | 字典名称 |
| dict_type | VARCHAR(100) | 字典类型编码（唯一） |
| status | CHAR(1) | 状态（0正常 1停用） |

**sys_dict_data 表**（字典数据）：

| 字段 | 类型 | 说明 |
|------|------|------|
| dict_code | BIGINT | 字典数据ID（主键，自增） |
| dict_sort | INT | 排序号 |
| dict_label | VARCHAR(100) | 字典标签（显示值） |
| dict_value | VARCHAR(100) | 字典值（实际值） |
| dict_type | VARCHAR(100) | 字典类型编码 |
| is_default | CHAR(1) | 是否默认（Y是 N否） |
| status | CHAR(1) | 状态（0正常 1停用） |

### 4.2 Redis 缓存策略

| Key | 说明 | 过期时间 |
|-----|------|---------|
| dict:type:{dictType} | 存储指定类型的字典数据列表 | 1小时 |

**缓存更新策略**：
- 新增/修改/删除字典数据时，清除对应类型的缓存
- 查询字典数据时，先从缓存获取，缓存不存在时从数据库查询并写入缓存

### 4.3 权限校验

字典类型和字典数据的增删改接口使用 `@PreAuthorize` 进行权限校验，按类型获取字典数据接口（下拉选项）无需认证。
