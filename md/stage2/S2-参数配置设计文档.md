## 一、需求分析

### 1.1 业务背景

参数配置用于管理系统中的动态配置项，如系统名称、Logo、版权信息等。通过参数配置，管理员可以在不修改代码的情况下调整系统行为。

### 1.2 功能需求

| 需求点 | 描述 | 优先级 |
|--------|------|--------|
| 参数列表 | 查询参数列表，支持分页和筛选 | P0 |
| 参数详情 | 根据参数ID查询参数详情 | P0 |
| 按Key查询 | 根据参数Key查询参数值（业务代码中使用） | P0 |
| 新增参数 | 创建新的参数配置 | P0 |
| 修改参数 | 更新已有的参数配置 | P0 |
| 删除参数 | 删除指定的参数配置 | P0 |

### 1.3 非功能需求

- 参数Key必须唯一
- 支持Redis缓存，提高查询性能
- 参数值支持多种类型（字符串、数字、JSON等）

## 二、技术方案

### 2.1 数据库设计

#### sys_config 表

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| config_id | BIGINT | PRIMARY KEY, AUTO_INCREMENT | 参数配置ID |
| config_name | VARCHAR(100) | NOT NULL | 参数名称 |
| config_key | VARCHAR(100) | NOT NULL, UNIQUE | 参数键名 |
| config_value | VARCHAR(500) | NOT NULL | 参数键值 |
| config_type | CHAR(1) | DEFAULT 'N' | 系统内置（Y是 N否） |
| status | CHAR(1) | DEFAULT '0' | 状态（0正常 1停用） |
| create_by | VARCHAR(64) | DEFAULT '' | 创建者 |
| create_time | DATETIME | DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| update_by | VARCHAR(64) | DEFAULT '' | 更新者 |
| update_time | DATETIME | NULL ON UPDATE CURRENT_TIMESTAMP | 更新时间 |
| remark | VARCHAR(500) | NULL | 备注 |

### 2.2 接口设计

#### 2.2.1 参数列表

```
GET /system/config/list
```

**请求参数**：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| pageNum | Integer | ❌ | 页码，默认 1 |
| pageSize | Integer | ❌ | 每页条数，默认 10 |
| configName | String | ❌ | 参数名称，模糊匹配 |
| configKey | String | ❌ | 参数键名，模糊匹配 |
| status | String | ❌ | 状态（0正常 1停用） |

**成功响应**：

```json
{
  "code": 200,
  "data": {
    "total": 10,
    "rows": [
      {
        "configId": 1,
        "configName": "系统名称",
        "configKey": "sysName",
        "configValue": "RuoYi",
        "configType": "Y",
        "status": "0",
        "remark": "系统名称配置",
        "createTime": "2026-07-17 10:00:00"
      }
    ]
  }
}
```

#### 2.2.2 参数详情

```
GET /system/config/{configId}
```

**成功响应**：同上（单条记录）

#### 2.2.3 按Key查询参数值

```
GET /system/config/key/{configKey}
```

**成功响应**：

```json
{
  "code": 200,
  "data": "RuoYi"
}
```

#### 2.2.4 新增参数

```
POST /system/config
```

**请求体**：

```json
{
  "configName": "系统版权",
  "configKey": "sysCopyright",
  "configValue": "2026 RuoYi",
  "configType": "N",
  "status": "0",
  "remark": "系统版权信息"
}
```

| 字段 | 类型 | 必填 | 校验规则 |
|------|------|------|----------|
| configName | String | ✅ | 2-100 字符 |
| configKey | String | ✅ | 2-100 字符，唯一 |
| configValue | String | ✅ | 最大 500 字符 |
| configType | String | ❌ | Y/N，默认 N |
| status | String | ❌ | 0/1，默认 0 |
| remark | String | ❌ | 最大 500 字符 |

**成功响应**：

```json
{
  "code": 200,
  "msg": "操作成功",
  "data": null
}
```

#### 2.2.5 修改参数

```
PUT /system/config
```

**请求体**：

```json
{
  "configId": 1,
  "configName": "系统名称",
  "configKey": "sysName",
  "configValue": "RuoYi Admin",
  "configType": "Y",
  "status": "0",
  "remark": "系统名称配置"
}
```

**成功响应**：同上

#### 2.2.6 删除参数

```
DELETE /system/config/{configIds}
```

**成功响应**：同上

## 四、缓存策略

### 4.1 Redis Key 设计

| Key | 说明 | 过期时间 |
|-----|------|---------|
| config:{configKey} | 存储参数值 | 1小时 |

### 4.2 缓存更新策略

- 新增/修改/删除参数时，清除对应Key的缓存
- 按Key查询参数时，先从缓存获取，缓存不存在时从数据库查询并写入缓存

## 六、数据库脚本

```sql
-- 参数配置表
DROP TABLE IF EXISTS sys_config;
CREATE TABLE sys_config (
    config_id    BIGINT NOT NULL AUTO_INCREMENT COMMENT '参数配置ID',
    config_name  VARCHAR(100) NOT NULL COMMENT '参数名称',
    config_key   VARCHAR(100) NOT NULL UNIQUE COMMENT '参数键名',
    config_value VARCHAR(500) NOT NULL COMMENT '参数键值',
    config_type  CHAR(1) DEFAULT 'N' COMMENT '系统内置（Y是 N否）',
    status       CHAR(1) DEFAULT '0' COMMENT '状态（0正常 1停用）',
    create_by    VARCHAR(64) DEFAULT '' COMMENT '创建者',
    create_time  DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    update_by    VARCHAR(64) DEFAULT '' COMMENT '更新者',
    update_time  DATETIME DEFAULT NULL ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    remark       VARCHAR(500) DEFAULT NULL COMMENT '备注',
    PRIMARY KEY (config_id)
) ENGINE=InnoDB AUTO_INCREMENT=100 COMMENT='参数配置表';
```

## 七、测试用例

| 测试场景 | 请求 | 预期结果 |
|---------|------|---------|
| 查询参数列表 | `GET /system/config/list` | 返回分页数据 |
| 查询参数详情 | `GET /system/config/1` | 返回参数信息 |
| 按Key查询参数 | `GET /system/config/key/sysName` | 返回参数值 |
| 新增参数 | `POST /system/config` | 创建成功 |
| 新增重复Key | `POST /system/config`，configKey重复 | 返回 400 错误 |
| 修改参数 | `PUT /system/config` | 更新成功 |
| 删除参数 | `DELETE /system/config/5` | 删除成功 |
| 删除系统内置参数 | `DELETE /system/config/1` | 返回 400 错误 |
| 权限不足访问 | 无权限用户访问 | 返回 403 |
